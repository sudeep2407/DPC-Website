# Darjeeling Prime Cab Services – Website

Modern, mobile-first static website for **Darjeeling Prime Cab Services**.

## How to Run Locally

### Option 1 – Simple (recommended)
1. Unzip the folder.
2. Double-click `index.html`  
   OR  
   Right-click → Open with Chrome / Firefox / Edge.

### Option 2 – Local server (best for full features)
```bash
# Using Python 3
cd darjeeling-prime-cab
python3 -m http.server 8000

# Then open http://localhost:8000
```

Or with Node:
```bash
npx serve .
```

## Pages Included
- `index.html` – Homepage with Instant Fare Estimator
- `fleet.html` – Vehicle fleet
- `services.html` – All services
- `about.html` – About the company
- `contact.html` – Contact form (opens WhatsApp)

## Features
- Instant fare estimator (demo calculation)
- WhatsApp & Call booking integration
- Fully responsive (mobile + desktop)
- Modern blue + white corporate design
- Floating WhatsApp / Call buttons
- Your selected logo used throughout

## Customize Before Going Live
1. Replace phone number `9733012345` with your real number (search & replace in all files).
2. Update email `info@darjeelingprimecab.com`.
3. Replace temporary vehicle photos with real photos of your fleet.
4. Add your real Google reviews / photos later.
5. Host on any free/paid hosting (Netlify, Vercel, GitHub Pages, GoDaddy, etc.).
